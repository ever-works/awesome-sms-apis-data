## Overview

Shree Tripada Infomedia India Pvt. Ltd. is a bulk SMS service company specializing in promotional SMS, transactional SMS, OTPs, and API integration.

## Features

- Message History
- Campaign Management
- Language Support
- Bulk SMS
- Import Contacts
- Real Time
- Group Messaging
- Two Way Messaging
- WhatsApp Business API
- RCS Messaging

## Deployment

Cloud-based (SaaS)
