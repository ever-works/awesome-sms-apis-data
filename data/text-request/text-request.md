## Overview

Text Request is a fully-featured SMS Marketing Software designed to serve enterprises and SMEs. It provides end-to-end solutions designed for web apps. This online bulk SMS system offers contact management, mobile coupons, mass texting, mobile keywords, and polls/voting in one place.

## Features

- API Integration
- Group Messaging
- Message Templates
- Contact Management
- Opt Out Management
- Drip Campaigns
- Delivery Receipts
- Longcodes
