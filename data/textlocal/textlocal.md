## Overview

TextLocal is a bulk SMS software platform that combines AI with real-time customer experiences for targeted SMS marketing. It gathers GDPR-compliant consents and supports campaigns for startups, SMBs, mid-market, and enterprises.

## Features

- API Integration
- Shortcodes
- Scheduled Messaging
- Language Support
- MMS Messaging
- Mobile Access
- Contact Management
- Two Way Messaging

## Deployment

Cloud-based software.
