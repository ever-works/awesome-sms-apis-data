## Overview

Mobile Text Alerts is a business texting software that provides a fully featured platform and API for SMS marketing and 2-way texting to help businesses engage with their audiences.

## Key Features

- Automated responses
- Link tracking
- Contact management
- Message personalization
- Drip campaigns
- Mobile access
- MMS support
- Shortcodes
