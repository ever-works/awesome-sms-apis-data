## Overview

Exotel is a cloud telephony and bulk SMS platform that enables businesses to send authentication and verification codes via SMS, mask phone numbers, and manage voice communications.

## Key Features

- SMS authentication and verification codes
- Phone number masking
- Virtual numbers
- API integration
- Multi-level IVR
- Call conferencing
- Call masking
- IVR system
- Custom greetings
- Call analytics
