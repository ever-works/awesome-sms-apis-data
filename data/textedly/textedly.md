## Overview

Textedly is an SMS marketing tool that simplifies mass texting for businesses.

## Features

- Opt In Management
- Drip Campaigns
- Reporting And Analytics
- Message History
- Two Way Messaging
- API Integration
- Compliance Tools
- Personalization

## Pricing

- Free: $0/month
- Plus: $25/month
- Enterprise: $40/month
- Elite: $55/month

## Deployment

Cloud-based (SaaS)
